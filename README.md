# Mechanicist Factorio

**Current version: v0.1.2 — Factorio 2.1 compatible**  
**Verified headless engine: Factorio 2.1.24 (build 87808)**

Mechanicus-inspired **English localization and lore retheme** for vanilla Factorio and official expansion content. The mod preserves original prototype identifiers; it does not add vehicles or tank features.

## Download the tested version

**[Download Mechanicist Factorio v0.1.2 from GitHub Releases](https://github.com/mrcalzon02/mechanicist-factorio/releases/tag/v0.1.2)**

In **Assets**, choose **mechanicist-factorio_0.1.2.zip**. Do NOT download GitHub's autogenerated Source code ZIP and do NOT use the obsolete root-level mechanicist-factorio_0.1.1.zip.

## Installation

1. Download **mechanicist-factorio_0.1.2.zip** from the release Assets.
2. Keep the mod ZIP **compressed** (do not extract). Copy it into Factorio's mods folder:
   - **Windows:** %APPDATA%\Factorio\mods\
   - **Linux:** ~/.factorio/mods/
   - **macOS:** ~/Library/Application Support/factorio/mods/
   - **Portable installation:** that installation's configured mods folder.
3. Disable or remove older Mechanicist versions. Start **Factorio 2.1**, enable **Mechanicist Factorio 0.1.2** under Mods, and restart if requested.
4. Optionally enable official **Elevated Rails, Recycler, Quality, and Space Age** modules, if owned. No third-party mod is required.

The mod ZIP already contains the correctly versioned top-level folder **mechanicist-factorio_0.1.2/**.

## Features, scope and limitations

- Mechanicus-inspired English names, descriptions, and lore for existing machines, items, recipes, technologies, and supported official expansion prototypes.
- Base retheme intensity: **off**, **standard**, or **heresy**.
- Optional lore/documentation remote interfaces.
- The historic **rename-quality** startup toggle is not currently wired into the data-stage patcher; Quality localization text is loaded independently of this toggle.
- Headless smoke tests do not guarantee every GUI element or Factoriopedia page has been visually inspected.
