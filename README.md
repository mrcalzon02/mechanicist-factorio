# Mechanicist Factorio

**Source:** [mechanicist-factorio_0.1.2/](mechanicist-factorio_0.1.2/) | **Factorio:** 2.1 | **Latest validated engine:** 2.1.24

Install the tested `mechanicist-factorio_0.1.2.zip` from the **mechanicist-factorio-installable** artifact of a successful [GitHub Actions run](https://github.com/mrcalzon02/mechanicist-factorio/actions/workflows/mechanicist-headless.yml).

The old root-level `mechanicist-factorio_0.1.1.zip` is a historical archive that is **not** the 2.1-tested package. See [mod README](mechanicist-factorio_0.1.2/README.md) for features, scope, and limitations.

CI builds and validates the exact ZIP against Factorio base, Elevated Rails, Quality/Recycler and full Space Age. No third-party mods are installed.
