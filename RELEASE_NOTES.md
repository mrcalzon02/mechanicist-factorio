# Mechanicist Factorio v0.1.2 — Factorio 2.1 compatibility

This is the **installable Mechanicist Factorio 0.1.2 release**, verified on the official **Factorio 2.1.24** Linux headless server (build 87808).

## Installation

Download **mechanicist-factorio_0.1.2.zip** under this GitHub release's **Assets** section (not GitHub's autogenerated Source code archives). Place the ZIP **without extracting it** into Factorio's mods folder, enable it under Mods, and restart if requested.

- Windows: **%APPDATA%\Factorio\mods\**
- Linux: **~/.factorio/mods/**
- macOS: **~/Library/Application Support/factorio/mods/**

Remove or disable an older Mechanicist copy. The repository's historical **mechanicist-factorio_0.1.1.zip** is obsolete. The companion **mechanicist-factorio_0.1.2.zip.sha256** is an integrity checksum, not a second installable mod.

## What's updated

- Metadata targets Factorio **2.1** with **base 2.1.0+**, and makes **Elevated Rails**, **Recycler**, **Quality**, and **Space Age** optional dependencies.
- Fixed data-stage load blockers and protected optional Space Age description localization lookups.
- Added isolated official Factorio headless testing for save creation, simulation and server startup.
- Reproducibly builds an installable versioned ZIP, compares against source, verifies SHA-256, and releases **only the exact ZIP that passes the headless tests**.
- Updated root and mod READMEs with accurate installation guidance, capabilities, limitations and evidence links.

## Known limits

This certifies **headless Factorio 2.1.24 compatibility** in the listed official-mod combinations. It does not claim that every GUI/Factoriopedia string is visually verified or that third-party integrations have been tested. The historic **rename-quality** startup toggle is not yet wired to the data-stage patcher.
