# Mechanicist Factorio 0.1.2

**Factorio version:** 2.1 — tested on 2.1.24, build 87808.  
**Official modules:** Base, optional Elevated Rails, Recycler, Quality, and Space Age.  
**Third-party mods:** Not required and not included in this isolated validation.

Mechanicus-inspired English localization/lore retheme, preserving vanilla prototype IDs. The mod does not contain tank/vehicle features mentioned in old 0.1.1 documentation.

## Install the verified mod

1. Open the [v0.1.2 GitHub Release](https://github.com/mrcalzon02/mechanicist-factorio/releases/tag/v0.1.2) and download **mechanicist-factorio_0.1.2.zip** under **Assets**. Do not download autogenerated source archives or the historical root-level 0.1.1 mod ZIP.
2. Place the mod ZIP **unchanged, without extracting it**, in Factorio's mods folder: Windows **%APPDATA%\Factorio\mods\**, Linux **~/.factorio/mods/**, or macOS **~/Library/Application Support/factorio/mods/**.
3. Disable or remove older Mechanicist versions. Enable **Mechanicist Factorio 0.1.2** in the in-game Mods menu and restart if prompted.
4. Official DLC is optional. Base-only Factorio 2.1 works; full Space Age plus Quality, Recycler and Elevated Rails has also passed.

The archived ZIP includes the required outer directory **mechanicist-factorio_0.1.2/**.

## Behavior and known limits

- Preserves Factorio's internal item, recipe, entity and technology identifiers.
- Changes displayed English names/descriptions and includes official Quality and Space Age locale content.
- Supports base-language intensity **off**, **standard**, or **heresy**, and optional documentation/lore interfaces.
- **rename-quality** startup setting is currently present but does not drive data-stage renames; the Quality locale file still loads.
- Headless validation does not visually check every GUI or Factoriopedia string.
- Tanks for Bob and Tech Priests are outside the scope of this **standalone/official-DLC** release and have not been asserted compatible by these tests.

## Build from source

From the repository root, run:

    python3 ci/package_mod.py --source mechanicist-factorio_0.1.2 --output-dir test-artifacts

CI additionally validates the produced archive's content and SHA-256, creates test saves, runs 1,200 ticks in each mode and starts isolated dedicated servers before publishing the tested package.
