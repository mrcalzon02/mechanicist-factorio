# Mechanicist Factorio 0.1.2

Mechanicus-inspired language retheme for **Factorio 2.1**. The mod preserves internal vanilla prototype IDs while applying thematic English names and descriptions to existing machines, items, recipes, technology and Space Age content.

**Required game:** Factorio 2.1 (verified with 2.1.24).
**Official DLC modules supported:** Elevated Rails, Recycler, Quality and Space Age, individually where applicable or together.
**Third-party mods:** none required for this release.

## Installing the verified package

Download `mechanicist-factorio_0.1.2.zip` from the **mechanicist-factorio-installable** artifact of the latest successful [Mechanicist Headless GitHub Actions](https://github.com/mrcalzon02/mechanicist-factorio/actions/workflows/mechanicist-headless.yml) run. The Actions artifact is a wrapper ZIP: extract it and put the contained `mechanicist-factorio_0.1.2.zip` **unchanged** into Factorio's `mods` directory. Do **not** use the root-level `mechanicist-factorio_0.1.1.zip`, which is an older, historical archive that predates the 2.1 compatibility fixes.

Only the updated source at `mechanicist-factorio_0.1.2/` is used for packaging and CI. The CI pipeline first packages this exact directory, then installs **that ZIP file** into an isolated Factorio installation and tests clean map creation, 1,200 ticks, and private dedicated-server startup in each official-mod configuration.

## What the current mod actually does

- Changes visible language and lore, not vanilla internal identifiers.
- Lets players select off, standard, or heresy language intensity for the base-game retheme.
- Provides English Quality and Space Age localization content.
- Provides optional lore/documentation remote interfaces when the client requests them.
- Does **not** implement the tanks and vehicle features incorrectly described in the old README; these are unrelated to this source tree.

## Test scope and limitations

A passing headless run establishes that the packaged mod loads and simulates on the tested engine. It does not validate interactive GUI layout, every Factoriopedia page, or every translated string visually. The `rename-quality` startup setting is present in the historical settings but is not currently wired into the data-stage patcher; Quality locale content is applied by the loaded locale file. Treat it as an outstanding UI/behavior consistency issue, not as a tested toggle.

The source archive contains a complete reproducible package and a SHA-256 digest generated by CI.
