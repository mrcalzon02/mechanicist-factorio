# Mechanicist Factorio v0.1.3 — localization repairs

**Factorio:** 2.1; official DLC optional; only English localization is shipped.

## Installation
Download the **mechanicist-factorio_0.1.3.zip** release asset from [GitHub](https://github.com/mrcalzon02/mechanicist-factorio/releases/tag/v0.1.3) or the existing [Mod Portal listing](https://mods.factorio.com/mod/mechanicist-factorio). Place the **unextracted ZIP** in your Factorio mods folder and remove/disable obsolete copies. No third-party mods are required.

## Repairs
- Type-specific Space Age localization prevents same-named entity, item, recipe and technology keys overwriting each other.
- The **rename-quality** setting controls Quality *prototype* renames via namespaced keys. Other static UI/tip strings remain English rethemes.
- Disabled base or expansion prototype rethemes now leave the original localized fields untouched.
- Space Age Informatron root title is defined.
- Static locale-key audits and actual Factorio data-stage probes cover standard, heresy, off, Quality, and Space Age cases.

**Caution:** Loading and headless server tests do not equal full visual GUI or every page's translation rendering. Optional third-party mod integrations remain outside this isolated official-mod release.
